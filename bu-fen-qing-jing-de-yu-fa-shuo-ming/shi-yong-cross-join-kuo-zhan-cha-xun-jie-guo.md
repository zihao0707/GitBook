# 使用 CROSS JOIN 擴展查詢結果

## 📖 背景說明

假設有兩組資料：

* **主資料表 B（MEB15\_0000）**
* **附加資料（固定三筆）**

我們希望將每一筆 B 資料都對應附加三筆資料。例如：

* 如果 B 有 2 筆資料，結果應該為 2 x 3 = 6 筆資料。

***

## 📂 原始資料結構

### 📌 附加資料（來源資料A）

```sql
-- 假設資料如下：
SELECT * FROM (
    SELECT 1765 AS meb53_0000, '2025/04/01' AS cal_date, 'N' AS is_holiday, '' AS cmemo, 'L1A-001' AS mac_code, 480 AS std_hour, 'm' AS std_unit
    UNION ALL
    SELECT 1766, '2025/04/02', 'N', '', 'L1A-001', 480, 'm'
    UNION ALL
    SELECT 1767, '2025/04/03', 'N', '', 'L1A-001', 480, 'm'
) AS A
```

### 📌 主資料表（B 查詢）

```sql
SELECT * FROM MEB15_0000
```

***

## 🧩 解法：使用 CROSS JOIN 實現對應展開

### 💡 語法說明

`CROSS JOIN` 會將兩張表的每一筆資料進行「笛卡兒積」的組合。也就是：

* B 有 N 筆資料
* A 有 M 筆資料
* 結果為 N x M 筆資料

### 🛠️ SQL 實作

```sql
SELECT B.*, A.*
FROM MEB15_0000 AS B
CROSS JOIN (
    SELECT 1765 AS meb53_0000, '2025/04/01' AS cal_date, 'N' AS is_holiday, '' AS cmemo, 'L1A-001' AS mac_code, 480 AS std_hour, 'm' AS std_unit
    UNION ALL
    SELECT 1766, '2025/04/02', 'N', '', 'L1A-001', 480, 'm'
    UNION ALL
    SELECT 1767, '2025/04/03', 'N', '', 'L1A-001', 480, 'm'
) AS A
```

## ✅ 小結

* 當你需要每筆主資料對應固定數量的明細資料時，`CROSS JOIN` 是非常合適的做法。
* 使用 `UNION ALL` 建立靜態資料集，便於靈活擴展應用場景。
